## Proyectos seleccionados

### [CSV Import Doctor](https://github.com/sgarciajerez/csv-import-doctor)

Aplicación integrada para Shopify, **en desarrollo**, para diagnosticar CSV de productos, filtrar incidencias, aplicar reparaciones controladas y previsualizar y exportar cambios.

- TypeScript y Shopify React Router.
- Análisis en un Web Worker cancelable.
- Los datos del CSV permanecen en el navegador del comerciante.

### [Andalucía En Línea](https://github.com/sgarciajerez/TFM)

Aplicación full stack de transporte público conectada a la API del Consorcio de Transportes de Andalucía para consultar rutas y horarios.

- Frontend responsive con JavaScript y backend con Node.js.
- Gestión de usuarios, autenticación básica y almacenamiento en MySQL.
- Integración de una API externa para consultar información actualizada.

### AutoContent AI / Tapa de Ocio

Plugin propio en PHP y JavaScript que integra la API de OpenAI para generar publicaciones con texto, imágenes y categorización. Utilizado en Tapa de Ocio, donde generó **más de 600 publicaciones**. La PWA incluyó más de 100 páginas adaptadas a móviles, soporte multiciudad y suscripciones con WooCommerce.

### [Digital Kit Creator Factory](https://github.com/sgarciajerez/digital-kit-creator-factory)

Factoría local en **Python**, en desarrollo, para crear plantillas Excel nativas, validar su estructura y funcionamiento y preparar materiales de entrega para kits digitales. Incluye controles de calidad y revisión humana antes de la publicación.
